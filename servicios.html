PYTHON LOCAL



Python es un lenguaje de programación de alto nivel, interpretado y multiparadigma, destacado por su sintaxis clara y legibilidad. Creado por Guido van Rossum en 1991, es gratuito y de código abierto. Es versátil y popular en desarrollo web, análisis de datos, inteligencia artificial y automatización.

Para comenzar a programar primero debemos descargar Python desde su página oficial.

1. Descargar Python

  1. Abrir el navegador.
  2. Ir a https://www.python.org
  3. Presionar el botón Download Python.

2. Instalar Python

  1. Buscar el archivo descargado.
  2. Ejecutar el instalador.
  3. Marcar la opción Add Python to PATH.
  4. Hacer clic en Install Now.

3. Verificar instalación

En la terminal escribir:

python --version

Comandos Básicos de Python

Comandos Básicos

  • print() - Mostrar información en pantalla
  • input() - Pedir datos al usuario
  • len() - Longitud de listas o cadenas
  • type() - Saber tipo de dato
  • int(), float(), str() - Convertir tipos de datos
  • + - * / % ** - Operaciones matemáticas
  • if, elif, else - Condicionales
  • for - Bucle para recorrer secuencias
  • while - Bucle mientras se cumpla condición
  • break - Salir de un bucle

Listas, Funciones y Archivos

  • list() - Crear lista o convertir a lista
  • append() - Agregar elemento al final de una lista
  • insert() - Insertar elemento en posición específica
  • pop() - Eliminar y devolver un elemento
  • remove() - Eliminar un elemento por valor
  • sort() - Ordenar lista de menor a mayor
  • reverse() - Dar vuelta la lista
  • range() - Generar secuencia de números
